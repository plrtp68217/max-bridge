# max-bridge

Веб-мессенджер на GREEN-API: отправка и получение текстовых сообщений в интерфейсе,
повторяющем тёмную тему MAX.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

1. На экране входа введите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
2. Создайте чат, указав номер получателя в международном формате (`79001234567`).
3. Отправляйте сообщения — ответы появятся в ленте автоматически.

Учётные данные, список чатов и история сообщений хранятся только в `localStorage` браузера.

## Настройки инстанса

В личном кабинете (Инстанс → Настройки) должны быть включены уведомления
`incomingWebhook`, `outgoingMessageWebhook` и `outgoingMessageStatus`
(статусы исходящих). **Поле URL webhook должно быть пустым** — иначе GREEN-API
отправляет уведомления на этот адрес, а не в очередь, которую читает приложение.

## Как устроено получение сообщений

1. `receiveNotification?receiveTimeout=20` — long polling очереди уведомлений.
2. Уведомление разбирается по `typeWebhook`:
   - `incomingMessageReceived` — входящее сообщение;
   - `outgoingMessageReceived` — сообщение, отправленное с телефона;
   - `outgoingMessageStatus` — статус доставки (галочки).

   `outgoingAPIMessageReceived` пропускается: это сообщения, отправленные самим
   приложением, они уже есть в ленте.
3. `deleteNotification` удаляет уведомление, иначе очередь не отдаст следующее.
4. При ошибке сети цикл ждёт 5 секунд и повторяет запрос.

**Важно про chatId в MAX.** У собеседника в MAX `chatId` — внутренний id
(например `"10000000"`), а не номер телефона. Поэтому при создании чата номер
сначала проверяется через `checkAccount`, и чат создаётся с полученным `chatId` —
тогда входящие попадают в тот же чат.

## Структура

```
src/
  api/greenapi.ts        запросы к GREEN-API
  context/               ChatProvider (состояние + цикл опроса), useChat
  components/            сайдбар, лента, поле ввода, иконки
  pages/                 вход, новый чат, основной экран
  utils/                 типы, localStorage, форматирование
```

## Ограничения

Поддерживаются только личные чаты и только текстовые сообщения (включая ответы-цитаты) — остальные типы
отображаются заглушкой. Групповые чаты, вложения, звонки и реакции вне задачи.

## Стек

React 19, TypeScript, React Router, Vite. Внешних UI-библиотек нет — вёрстка и иконки свои.
